# 프로젝트 개발 및 Git 관리 규칙

## Git 자동 커밋 및 푸시 규칙
- 사용자의 지시를 받아 완료된 작업(코드 수정, 문서 업데이트 등)은 작업이 성공적으로 종료될 때마다 자동으로 Git 변경사항을 반영합니다.
- **커밋 메시지**: 작업 내용을 상세히 설명하는 **한글 커밋 메시지**로 작성하여 커밋을 진행합니다.
- **동기화**: 커밋 후 원격 저장소의 최신 내역을 반영하고(`git pull`), 원격 저장소로 자동으로 푸시(`git push`)하여 동기화를 완료합니다.

## 컴포넌트 및 스타일 구현 규칙
- 사용자가 제공하는 원본 자료(HTML, CSS, 코드 등)의 구조, 스타일(border-radius, 색상, 여백, 폰트, 크기 등)을 임의로 변형하거나 자의적으로 추가하지 않습니다.
- 반드시 **사용자가 제공한 자료 그대로 1:1 완벽하게 일치**하도록 작업합니다.
